// ANDROID SETUP

LYRICX ON ANDROID.

A dedicated phone app, not a wrapped desktop window. It finds tracks on YouTube Music through a native bridge, plays through the official embed and includes a Malayalam / English switch.

  1. 01
    DOWNLOAD THE APK

    Tap the Android download button above and wait for the 4 MB file.

  2. 02
    ALLOW THE INSTALL

    When Android asks, allow installs from your browser or file manager.

  3. 03
    OPEN AND PLAY

    Launch LYRICX, find a track on YouTube Music and press play.

HEADS UP: the APK is debug-signed, so Android may show “unsafe app blocked”. Tap More details → Install anyway. Android 8.0 or newer is required. Playback uses the official YouTube embed; if a track is blocked in-app, use the “Open in YouTube Music” button.
