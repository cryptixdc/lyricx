A player that gets out of the way

Everything you need, nothing you don't.

One source

YouTube Music only — search, playlists, lyrics and accounts in one focused place.

Living visualizers

Over twenty lyric animation styles, from quiet still frames to full motion pieces.

Made for Malayalam

Bundled Noto, Manjari and Baloo fonts, a Malayalam interface and translated guides.

Audio-reactive

Cover-derived colour themes and fluid shaders that follow the music.

Lyrics on your stream

A browser display window and wallpaper mode for a clean on-screen look.

Works offline

Fonts and assets ship with the app, so your interface never depends on a CDN.

On macOS

The build is ad-hoc signed. If macOS refuses to open it, right-click the app, choose Open, then Open again.

On Linux

Make the AppImage executable with chmod +x, or install the package with sudo apt install ./lyricx.deb.
